## Необходимые модули

###### __Модуль generators__

Модуль generators предназначен для реализации функций и генераторов, связанных с обработкой данных транзакций и созданием различных последовательностей значений.

###### Функции модуля

_Функция filter_by_currency()_

Функция фильтрует список транзакций по валюте операций. Она принимает два аргумента:

`transactions:` Список словарей, каждый из которых представляет одну транзакцию.

`currency:` Валюта, по которой производится фильтрация.
Возвращается итератор, выдающий по одной транзакции за раз, где поле 'currency' совпадает с указанной валютой.

Пример использования:


`transactions = [
    {'amount': 100, 'currency': 'USD'},
    {'amount': 200, 'currency': 'EUR'}
]`

`for transaction in filter_by_currency(transactions, 'USD'):
    print(transaction)`

_Генератор transaction_descriptions()_

Этот генератор принимает список транзакций и последовательно возвращает описания каждой операции.

Пример использования:


`transactions = [
    {'description': 'Покупка продуктов', 'amount': 100},
    {'description': 'Оплата услуг', 'amount': 200}
]`

`for description in transaction_descriptions(transactions):
    print(description)`

_Генератор card_number_generator()_

Генерирует банковские карты формата XXXX XXXX XXXX XXXX, начиная с указанного начального значения и заканчивая указанным конечным значением.

Параметры генератора:

start: Начальная карта (формат строки вида "0000 0000 0000 0001").

end: Конечная карта (формат строки вида "9999 9999 9999 9999").

Принимает диапазон возможных номеров карт и генерирует каждую карту по порядку.

Пример использования:


`gen = card_number_generator('0000 0000 0000 0001', '0000 0000 0000 0005')
for number in gen:
    print(number)`
